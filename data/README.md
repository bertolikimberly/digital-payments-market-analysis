# Data source

This analysis uses the **country-level CSV** from the [World Bank Global Findex Database 2025](https://www.worldbank.org/en/publication/globalfindex/download-data).

Download the CSV and save it at:

`data/GlobalFindexDatabase2025.csv`

The notebook reads the file from that relative path. The dataset is not bundled here; the notebook retains the saved charts and other outputs from the analysis.
